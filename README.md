# Sociologins grunder – begrepp

Interaktivt övningsprogram för gymnasieelever.

## Delar
1. Vad är sociologi? – quiz: 7 slumpade frågor ur en bank med 20 frågor, tre svarsalternativ.
2. Begreppsquiz: 15 frågor. De sista tre är alltid mikro-, meso- och makronivå.
3. Begreppskort: 11 centrala sociologiska begrepp.

Programmet körs helt i webbläsaren och fungerar på GitHub Pages.
